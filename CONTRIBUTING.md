# Contributing Guide

Thanks for your interest in contributing! This document explains how to propose changes to this repository.

## How to contribute

1. **Open an issue first.** Before writing code, open an issue describing the bug or feature so the team can discuss the approach.
2. **Fork or create a branch.** Do your work on a dedicated branch rather than on `main`.
3. **Keep changes small.** Small, focused pull requests are easier to review and get merged faster.
4. **Write clear commit messages.** Explain *why* the change is needed, not just what changed.
5. **Be responsive in review.** Answer questions and address feedback promptly so reviews don't stall.

All changes must be reviewed before they are merged.
